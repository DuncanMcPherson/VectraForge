# VectraForge

VectraForge is a cross-platform IDE for the [Vectra programming language](https://gitlab.com/vectra-lang/vectra) (VectraLang). It is built with .NET and Avalonia UI, targeting Windows, macOS, and Linux.

## Features

> VectraForge is in early development. This list reflects planned features.

- Syntax highlighting and semantic analysis for VectraLang
- Project and file management
- Integrated build and run toolchain
- Cross-platform desktop support (Windows, macOS, Linux)

## Getting Started

### Prerequisites

- [.NET 10 SDK](https://dotnet.microsoft.com/download)

### Build

```bash
git clone https://gitlab.com/vectra-lang/vectra-forge.git
cd vectra-forge
dotnet build
```

### Run

```bash
dotnet run --project VectraForge
```
